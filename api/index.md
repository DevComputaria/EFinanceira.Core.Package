# Referência da API

Documentação de referência para as bibliotecas `EFinanceira.Core` e `EFinanceira.Messages`.

## Namespaces principais

- **EFinanceira.Core.Abstractions** — interfaces base (`IEFinanceiraMessage`, `IMessageBuilder<T>`, `IXmlSerializer`, `IXmlSigner`, etc.)
- **EFinanceira.Core.Validation** — validação XML contra schemas XSD
- **EFinanceira.Core.Serialization** — serialização de objetos para XML
- **EFinanceira.Messages.Builders** — builders fluentes para eventos, lotes e consultas

Explore as classes e interfaces usando a navegação lateral.
